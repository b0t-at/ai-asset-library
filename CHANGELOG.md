# Changelog

All notable changes to the b0t-at design foundation. Versions are git tags (`vX.Y.Z`); consumers pin to them.

## 0.1.1 — 2026-09-04

Review pass after the initial release.

- **Fixed:** cascade layers renamed from `b0t.base/components/utilities` to Tailwind's `base/components/utilities`. Previously, in a Tailwind v4 project the b0t layers were declared after Tailwind's and would have overridden utilities (e.g. `h1` styles beating `text-sm`). An explicit `@layer base, components, utilities;` order statement is emitted in `base.css` and the bundle.
- **Fixed:** `.b0t-menu__item` no longer removes the focus outline; keyboard focus now shows the 2px ring inside the item.
- **Fixed:** topbar on narrow viewports — brand no longer wraps, `.b0t-nav` scrolls horizontally instead of overflowing.
- **Fixed:** `.b0t-menu[popover]` no longer resets `inset` without positioning (which parked it at the viewport origin). It now anchors below its invoker where CSS anchor positioning exists and falls back to the UA's centered placement elsewhere.
- **Fixed:** `scripts/preview.mjs` answers 400 to malformed URLs instead of crashing.
- **Fixed:** showcase validity — no nested `<main>`, a single `<h1>`, brand copy says "dotted zero".
- **Added:** `brand/png/` (app icons 512/192/180, favicon 32/16, transparent mark and wordmark PNGs) generated by a dependency-free SDF rasteriser (`scripts/build-brand.mjs`, `npm run build:brand`, verified by `npm run check`); `brand/site.webmanifest` template.
- **Added:** Tailwind theme now also maps `text-xs … text-5xl` (with b0t line-heights and tracking), `leading-*`, `tracking-*`, `--container-*`, `--default-transition-duration/-timing-function`. Tailwind's defaults for these namespaces are reset.
- **Added:** version stamp in every generated file; `version` export in `dist/tokens.mjs` and `dist/tokens.json`.
- **Changed:** the `t` hook in the wordmark is a true circular arc (`a12 12 0 0 0 12 12`) so SVG and PNG geometry match exactly.
- **Changed:** inline wordmark snippets carry `height="24"` and a color fallback so they degrade sanely if the stylesheet fails to load.
- **Docs:** consumption paths rewritten — CDN (jsDelivr) as primary, vendored bundle via `curl`, npm-from-GitHub; pinning guidance.
- **Docs:** showcase honours the 12px text floor; `theme-color` meta added.

## 0.1.0 — 2026-09-04

Initial foundation.

- Tokens: OKLCH primitive scales (ink, petrol, moss, amber, rust, plum), semantic roles for light and dark, typography, spacing, radius, shadow, motion, layout.
- Build: `scripts/build-tokens.mjs` generates `css/tokens.css`, `css/b0t.css`, `tailwind/theme.css`, `dist/tokens.{json,mjs}` with a WCAG contrast gate.
- CSS: `base.css` (reset, type, focus), `components.css` (button, field, input, select, textarea, checkbox, switch, card, stat, badge, alert, table, tabs, topbar, nav, sidenav, breadcrumb, kbd, menu, dialog, toast, progress, spinner, skeleton, avatar, empty state, page header, footer), `utilities.css` (container, stack, cluster, grid, prose, text helpers, visually-hidden, skip link).
- Brand: wordmark (light/dark/mono), dotted-zero mark, app icon, theme-aware favicon, OG template, usage rules.
- Docs: principles, color, typography, layout, components, motion, accessibility, content, iconography & imagery, for-agents, framework recipes.
- Templates: `starter.html`, Copilot instructions snippet for consuming repos.
- Examples: `showcase.html` kitchen sink.
